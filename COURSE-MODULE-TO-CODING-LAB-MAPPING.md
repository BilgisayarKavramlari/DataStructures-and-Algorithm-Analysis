# Course Module to Coding Lab Mapping

This document maps official eLearning Course Modules to GitHub Coding Labs.

## Terminology

| Term | Meaning |
|---|---|
| Course Module | Official eLearning theory unit |
| Coding Lab | GitHub practice folder |

GitHub folders should use the `lab-XX-title` naming convention.

## Design Principle

Every major theory topic should have a visible practical counterpart.

A practical counterpart may be:

- a complete Java implementation,
- an educational implementation,
- a trace demo,
- a comparison driver,
- an invariant checker,
- a Java library connection,
- or a written complexity and design exercise.

No major Weiss topic covered in the course should be invisible in the repository.
