# Weekly Practice Schedule

This document maps the weekly theory sequence to the GitHub Coding Labs.

## Important Terminology

- **Course Module**: official eLearning/theory unit.
- **Coding Lab**: GitHub practice folder with Java examples, tracing exercises, and implementation tasks.

Midterm weeks do not include a regular second-class live practice session because the second class is used for the exam. In those weeks, the related Coding Labs may still be visible as preview, self-practice, or review material.

## Instructor Notes

The schedule is a roadmap, not a rigid guarantee. Adjustments may be made depending on class progress, student needs, exam logistics, assignment timing, or eLearning updates.

Students should use the eLearning Course Modules as the official source of deadlines and graded activities. This GitHub repository is the practical companion for coding, tracing, experimentation, and review.
