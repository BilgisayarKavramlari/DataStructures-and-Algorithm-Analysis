# Wednesday Practice Teaching Guide

Use the `practice-module-*` folders as instructor-facing live coding modules. The `lab-*` folders remain student-facing Coding Labs. For each session, choose the matching Course Module, open the practice module README, compile with `javac *.java`, run `PracticeModuleXXDemo`, then run `TraceDemo`. Ask students to state invariants, edge cases, and complexity after each trace. Do not paste textbook code or copyrighted slides; all examples are original educational Java.

## Suggested Session Pattern

1. Five minutes: connect the Course Module theory to the practice module.
2. Fifteen minutes: run the main demo and trace state changes.
3. Fifteen minutes: modify an input live and ask students to predict output.
4. Ten minutes: compare alternatives and discuss complexity.
5. Five minutes: assign the matching Coding Lab for student practice.
