# Academic Integrity and AI Use

## Purpose of the Coding Labs

The Coding Labs are provided to help students understand data structures and algorithm analysis through Java examples, tracing exercises, implementation practice, and design questions.

Students are encouraged to read, run, modify, and experiment with the examples.

## Learning Expectations

In CS 3345, learning means more than producing a working program.

Students should be able to explain:

- what the code does,
- why the data structure invariant is correct,
- how an operation changes the structure,
- what the time complexity is,
- what the space complexity is,
- what edge cases exist,
- what design tradeoffs were made.

## Use of AI Tools

AI tools may be useful for studying, asking conceptual questions, generating practice examples, or reviewing code.

However, students remain responsible for understanding and explaining their own work.

For graded assignments, quizzes, and exams, students must follow the official syllabus, eLearning instructions, and instructor announcements.

## Acceptable Study Uses

Depending on the assignment instructions, acceptable study uses may include:

- asking for conceptual explanations,
- generating additional practice problems,
- reviewing a compiler error,
- comparing two approaches,
- asking for hints,
- testing understanding through questions.

## Unacceptable Uses

Unless explicitly allowed by the instructor, students should not:

- submit AI-generated work as their own without understanding it,
- use AI to bypass the learning process,
- copy code into graded submissions without attribution or permission,
- use tools during exams or quizzes when not allowed,
- misrepresent authorship or understanding.

## Instructor Reminder

The official course syllabus and eLearning announcements override this repository document.
