# Legacy Mapping

This repository previously used the word "module" for some GitHub practice folders. That terminology conflicted with the official eLearning Course Modules.

The repository now uses:

- **Course Module** for eLearning/theory units.
- **Coding Lab** for GitHub practice folders.

## Old-to-New Folder Mapping

| Old Practice Folder Name | New Coding Lab Folder Name |
|---|---|
| `module-01-java-review` | `lab-01-java-review` |
| `module-02-data-structures-review` | `lab-02-adt-linear-structures-review` |
| `module-03-java-collections` | `lab-03-java-collections` |
| `module-04-growth-rates` | `lab-04-growth-rates` |
| `module-05-recursion-factorial-fibonacci` | `lab-05-recursion-factorial-fibonacci` |
| `module-06-maximum-subsequence-sum` | `lab-06-maximum-subsequence-sum` |
| `module-07-formal-algorithm-analysis` | `lab-07-formal-algorithm-analysis` |

## Student Note

If an older announcement or saved link refers to a `module-*` folder in GitHub, use the corresponding `lab-*` folder instead.

The eLearning Course Modules are still called Course Modules. Only the GitHub practice folders have been renamed as Coding Labs.
