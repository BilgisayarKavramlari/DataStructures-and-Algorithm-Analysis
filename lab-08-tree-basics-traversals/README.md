# Coding Lab 08: Tree Basics and Traversals

## Related Course Module

Course Module 7: Trees and Traversals

## Related Weiss Topic

Mark Allen Weiss, *Data Structures and Algorithm Analysis in Java*: Tree terminology, height, depth, and traversal orders.

## Learning Objectives

After completing this Coding Lab, students should be able to:

1. Explain the central invariant or algorithmic idea.
2. Trace the main operation step by step.
3. Compile and run plain Java examples without packages or external libraries.
4. Analyze best-case, average-case when appropriate, worst-case, and space complexity.
5. Compare the approach with at least one alternative data structure or algorithm.

## How to Compile

From this lab folder:

```bash
javac *.java
```

## How to Run

Example:

```bash
java TreeNode
```

## Suggested Student Workflow

1. Read this README before opening the Java files.
2. Compile the Coding Lab with `javac *.java`.
3. Run the suggested demo and record the output.
4. Trace one operation manually using paper or comments.
5. Modify one input sequence and predict the new output before rerunning.
6. Answer the complexity and design questions in complete English sentences.

## Student Tasks

1. Identify the invariant or rule that must remain true after each operation.
2. Add one small input case that exercises an edge condition.
3. Explain how the implementation would change for a larger or more realistic input.

## Complexity and Design Questions

1. What is the best-case running time of the main operation?
2. What is the worst-case running time of the main operation?
3. What space is required beyond the input itself?
4. Which input pattern causes the most work?
5. Which alternative covered in another Coding Lab could solve a related problem?

## Expected Takeaways

Students should connect the Java implementation to the data structure invariant, the operation trace, and the asymptotic analysis. Advanced structures in this repository are educational implementations; they emphasize invariants, rotations, splitting, promotion, or tracing rather than production library completeness.
